# Code of Conduct

Org AI Force uses a professional, evidence-oriented contribution standard.

## Expected behavior

- be respectful and constructive
- critique implementation and architecture, not people
- provide reproducible detail for bugs and claims
- protect credentials and sensitive data
- clearly distinguish prototypes, mocks and production-ready behavior
- consider accessibility, security and operator impact in UI changes

## Unacceptable behavior

Harassment, discriminatory language, personal attacks, publishing private information, credential disclosure, spam, or knowingly misleading capability/adoption claims are not acceptable.

## Maintainer response

Maintainers may edit or remove content and restrict participation when required to protect contributors, users or project integrity.
