# Portfolio Roadmap — Org AI Force

## Now — prove governance depth

- strengthen role/permission tests across frontend and backend boundaries
- make tool approval and denial states easy to demonstrate
- keep the implemented/mock/planned matrix current
- add deterministic failure fixtures for retrieval, tools and browser workers

## Next — evaluation and observability

- correlate agent run, retrieval, tool and approval events
- add agent scorecard/evaluation fixtures
- document operational metrics and readiness thresholds
- add trace-oriented recruiter/demo views without exposing secrets

## Later — production-oriented platform boundaries

- multi-tenant policy boundaries where justified
- broader connector contracts behind a consistent tool registry
- hardened worker queues, idempotency and execution isolation
- deployment-specific vaulting, HTTPS and secret rotation guidance

## Portfolio quality gates

- architecture changes update an ADR
- every public capability is marked implemented, demo-safe or planned
- protected operations remain server-governed
- visible citations and tool results preserve provenance
